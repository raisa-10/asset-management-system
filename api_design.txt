USER MANAGEMENT

1. Feature: Create a new user

API Endpoint: POST /api/users

Database Action:
INSERT into users (name, email, role, password_hash, created_at)

2. Feature: View all users

API Endpoint: GET /api/users

Database Action:
SELECT * FROM users

3. Feature: View a single user

API Endpoint: GET /api/users/{user_id}

Database Action:
SELECT * FROM users WHERE id = user_id

4. Feature: Update user details

API Endpoint: PUT /api/users/{user_id}

Database Action:
UPDATE users SET name, email, role WHERE id = user_id

5. Feature: Delete a user

API Endpoint: DELETE /api/users/{user_id}

Database Action:
DELETE FROM users WHERE id = user_id

====================================
ASSET ASSIGNMENT

11. Feature: Assign an asset to a user

API Endpoint: POST /api/assignments

Database Action:
INSERT into assignments (user_id, asset_id, assigned_date)
AND UPDATE assets SET status='Assigned' WHERE id = asset_id

12. Feature: View all assignments

API Endpoint: GET /api/assignments

Database Action:
SELECT * FROM assignments

13. Feature: View assignment history of a specific user

API Endpoint: GET /api/users/{user_id}/assignments

Database Action:
SELECT * FROM assignments WHERE user_id = user_id

14. Feature: Return an assigned asset

API Endpoint: PUT /api/assignments/{assignment_id}/return

Database Action:
UPDATE assignments SET return_date = CURRENT_DATE
AND UPDATE assets SET status='Available' WHERE id = asset_id

SEARCH & FILTER

18. Feature: Search assets by name

API Endpoint: GET /api/assets?search={keyword}

Database Action:
SELECT * FROM assets WHERE name LIKE '%keyword%'

19. Feature: Filter assets by status

API Endpoint: GET /api/assets?status={status}

Database Action:
SELECT * FROM assets WHERE status = status

20. Feature: Filter assets by category

API Endpoint: GET /api/assets?category={category}

Database Action:
SELECT * FROM assets WHERE category = category

AUTHENTICATION

21. Feature: Register a new system account

API Endpoint: POST /api/auth/register

Database Action:
INSERT into users with hashed password

22. Feature: Login to the system

API Endpoint: POST /api/auth/login

Database Action:
SELECT user WHERE email matches AND verify password hash

23. Feature: Logout from the system

API Endpoint: POST /api/auth/logout

Database Action:
Invalidate authentication token/session
